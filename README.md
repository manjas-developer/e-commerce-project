# 🛒 ABCD General Store CLI

A simple and interactive Python command-line store application.

## ✨ Features
- 📋 Displays item catalog and unit prices
- 🔍 Automatically logs out-of-stock requests to `missing_item.txt`
- 🧮 Dynamic total price calculation based on quantity
- 📝 Saves orders with delivery addresses to `order_details.txt`
- 💳 UPI payment details and order confirmation

## 🚀 How to Run
```bash
python main.py
